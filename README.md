# Сердце Фантазии — инструменты ГМ

Модуль Foundry VTT для кампании «Сердце Фантазии» (Pathfinder 2e).
Здесь живут все собственные механики и макросы кампании.

**Требования:** Foundry V13–V14, система PF2e 8.x.
**Рекомендуется:** [Cinematic Cut-ins](https://theglitchsmith.com/docs/cinematic-cut-ins/) — кадры Срыва на экране у всех игроков.

## Установка

Foundry (или The Forge) → Add-on Modules → Install Module → в поле **Manifest URL** вставить:

```
https://github.com/Fabushka/heart-of-fantasy/releases/latest/download/module.json
```

Потом включить модуль в мире: Game Settings → Manage Modules → «Сердце Фантазии — инструменты ГМ».

При первом запуске модуль сам создаёт папку макросов **«Сердце Фантазии»**. Макросы из неё можно перетащить на хотбар.

## Что внутри

### Ужас (Horror Mode, Adventures+ стр. 73–76)

Работает сам, как только модуль включён. Ничего запускать не нужно.

- **Рост Ужаса.** Натуральная 1 у персонажа или натуральная 20 у врага на любом броске: Ужас +1 всей партии в зоне. В бою не чаще раза за раунд.
- **Расширенный диапазон.** Натуральные 2…Ужас на своих бросках: степень успеха на ступень хуже. Натуральные (21 − Ужас)…19 у врагов против персонажа: на ступень лучше. PF2e пересчитывает это сам.
- **Срыв** на Ужасе 5: 1d4. Страх (убегает 2 раунда), Апатия (заворожён и обездвижен 2 раунда), Ярость (в замешательстве, снимается чистой проверкой DC 11 при получении урона), Героизм (Ужас падает до 1 и 1d5 бафф).
- **Проверка Ужаса** в конце каждого раунда боя: чистая проверка DC 1 + суммарный Ужас партии. Результат видит только ГМ.
- **Испуги** (таблица d20). Карточка в чате с описанием, целями и кнопками проверок. Игроки бросают сами, последствия накладываются автоматически.
- **Конец Испугов:** когда Ужас всей партии снижен до 1 или партия покинула зону.

### Макросы

| Макрос | Кто | Что делает |
|---|---|---|
| Ужас — управление | ГМ | Войти в зону, ±1 Ужас, Бегство весь ход (−2), выйти из зоны, Срыв, проверка за 10 минут исследования, Испуг вручную, снять Испуги |
| Срыв | ГМ | Срыв выделенным персонажам вручную |
| Подавить ужас | игроки | Вне боя: Воля против DC уровня, успех −1 Ужас, крит −2, крит. провал — Испуг |
| Предотвратить панику | игроки | В бою: то же самое |

### Кадры Срыва (Cinematic Cut-ins)

Если модуль Cinematic Cut-ins включён, при Срыве у всех на экране появляется кадр с портретом персонажа и названием Срыва.
Чтобы поставить свой кадр, создай в Cinematic Cut-ins пресет с одним из имён:

- `Срыв: Страх`
- `Срыв: Апатия`
- `Срыв: Ярость`
- `Срыв: Героизм`

Сначала ищется личный пресет персонажа, потом глобальный. Если пресета нет, показывается заготовка.

## Настройки

Game Settings → Configure Settings → «Сердце Фантазии — инструменты ГМ»:

- включение подсистемы Ужаса;
- кому растёт Ужас: всей партии в зоне (по книге) или только бросившему;
- лимит «раз за раунд»;
- учитывать ли чистые проверки;
- сообщения в чат о росте Ужаса;
- проверка Ужаса в конце раунда;
- перезарядка Испуга в раундах (по книге 10);
- показ кадров Срыва.

## Для скриптов

```js
const dread = game.modules.get("heart-of-fantasy").api.dread;
dread.manage();                       // диалог управления
dread.enterZone(actors);              // ввести персонажей в зону
dread.addDread(actors, "Причина");    // +1 Ужас без лимита
dread.lowerDread(actors, 1);          // −1 Ужас
dread.meltdown(actor);                // Срыв
dread.triggerScare(dread.partyInZone(canvas.scene), canvas.scene, "причина", { force: true });
```

## Выпуск новой версии

GitHub → Releases → Draft a new release → тег `v0.1.1` → Publish release.
GitHub Actions сам проставит версию, соберёт `module.zip` и приложит его к релизу.
Foundry увидит обновление по той же ссылке на манифест.
