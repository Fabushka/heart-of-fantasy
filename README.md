# Сердце Фантазии — инструменты ГМ

Модуль Foundry VTT для кампании «Сердце Фантазии» (Pathfinder 2e).
Здесь живут все собственные механики кампании. Каждая механика — отдельная подсистема в своей папке.

**Требования:** Foundry V13–V14, система PF2e 8.x.

## Установка

Foundry (или The Forge) → Add-on Modules → Install Module → в поле **Manifest URL** вставить:

```
https://github.com/Fabushka/heart-of-fantasy/releases/latest/download/module.json
```

Потом включить модуль в мире: Game Settings → Manage Modules → «Сердце Фантазии — инструменты ГМ».
Макросы модуль создаёт сам в папке **«Сердце Фантазии»**.

## Устройство

```
core/                   общее: запуск, настройки, макросы, кнопки в чате, помощники PF2e
subsystems/dread/       подсистема «Ужас»
  index.js              паспорт подсистемы: настройки, запуск, макросы, API
  state.js              эффект Ужаса и расширенный диапазон
  growth.js             рост Ужаса, разбор бросков, Подавить ужас / Предотвратить панику
  meltdown.js           Срыв: передышка, звук, карточка
  meltdowns.js          таблица Срывов (5 состояний × 3 варианта)
  scares/engine.js      Испуги: карточка, ожидание проверок, итоги, конец Испугов
  scares/combat.js      таблица Испугов в бою (20)
  scares/exploration.js таблица Испугов в исследовании (20)
  scares/afflictions.js болезни и яды
  scares/summons.js     существа из Испугов (Monster Core)
  dread.css             оформление карточек
  sounds/heartbeat.ogg  сердцебиение при Срыве
```

Новая подсистема — новая папка в `subsystems/` и одна строка в `core/main.js`.

## Подсистема «Ужас»

Horror Mode из Adventures+ (стр. 73–76) с домашними правилами кампании. Работает сама, как только модуль включён.

- **Рост Ужаса.** Критический провал персонажа или критический успех врага: Ужас +1 всей партии в зоне. В бою не чаще раза за раунд. Переброс не считается.
- **Расширенный диапазон.** Натуральный результат на d20 не выше Ужаса — как натуральная 1: степень успеха на ступень хуже. Ужас 1 — без штрафа. Враги бонусов от Ужаса не получают.
- **Срыв** на Ужасе 5: 1d5 состояние (Отчаяние, Ярость, Паранойя, Ужас, Преодоление Ужаса) и 1d3 вариант. Ужас падает до 1, звучит сердцебиение, в чате — карточка Срыва. Затем 3 раунда передышки: новый Срыв не случается. Если к концу передышки Ужас 5 — Срыв сразу.
- **Проверка Ужаса** в конце каждого раунда боя и кнопкой за 10 минут исследования: чистая проверка DC 1 + суммарный Ужас партии. Меньше DC — Испуг.
- **Испуги.** Две таблицы по 20: бой (механика, существа) и исследование (нарратив, ловушки, болезни, яды). Игроки бросают проверку из карточки со штрафом −(Ужас − 1); эффект накладывается только после броска, по степени успеха.
- **Конец Испугов:** когда Ужас всей партии снижен до 1 или партия покинула зону. Эффекты Испугов снимаются, пропавшие вещи возвращаются, призванные существа исчезают. Обычные состояния (напуган, истощён, утомлён), болезни и яды остаются.

### Макросы

| Макрос | Кто | Что делает |
|---|---|---|
| Ужас — управление | ГМ | Войти в зону, ±1 Ужас, Бегство весь ход (−2), выйти из зоны, Срыв (случайный или выбранный), проверка за 10 минут исследования, Испуг (случайный или выбранный), снять Испуги |
| Срыв | ГМ | Случайный Срыв выделенным персонажам |
| Подавить ужас | игроки | Вне боя: Воля против DC уровня; успех −1 Ужас, крит −2, крит. провал — Испуг |
| Предотвратить панику | игроки | В бою: то же самое |

### Настройки

Game Settings → Configure Settings → «Сердце Фантазии — инструменты ГМ»: включение подсистемы; кому растёт Ужас; лимит «раз за раунд»; чистые проверки; сообщения о росте; проверка в конце раунда; перезарядка Испуга; длина передышки после Срыва; звук Срыва и его громкость.

### Для скриптов

```js
const dread = game.modules.get("heart-of-fantasy").api.dread;
dread.manage();                                     // диалог управления
dread.enterZone(actors);                            // ввести персонажей в зону
dread.addDread(actors, "Причина");                  // +1 Ужас без лимита
dread.meltdown(actor, { state: 2, variant: 3 });    // конкретный Срыв (или без второго аргумента — случайный)
dread.triggerScare(dread.partyInZone(canvas.scene), canvas.scene, "причина", { force: true, table: "combat", n: 7 });
```

## Выпуск новой версии

1. Дописать раздел `## X.Y.Z` в `CHANGELOG.md`.
2. GitHub → Actions → Release → Run workflow → `X.Y.Z` (или Releases → Draft a new release → тег `vX.Y.Z` → Publish).

GitHub Actions сам проставит версию, соберёт `module.zip`, создаст релиз с описанием из CHANGELOG и приложит файлы.
Foundry увидит обновление по той же ссылке на манифест.
